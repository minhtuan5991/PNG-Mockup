# PNG Mockup 1.1.0

## Điểm mới

- Chọn ổ đĩa hoặc thư mục cha; bộ cài tự tạo thư mục `PNG Mockup`.
- Thư mục cài hiển thị file chạy, `Uninstall.exe`, `Show technical files.exe`
  và các thư mục làm việc `PNG`, `Mockup`, `Output`. File kỹ thuật được ẩn theo
  thuộc tính của riêng app, không thay đổi cài đặt Explorer toàn hệ thống.
- Có thể hiện/ẩn file kỹ thuật bằng công cụ đi kèm.
- Gỡ cài đặt giữ cấu hình, thiết kế, kết quả, nhật ký và các file ngoài chương trình.
- Mỗi lần mở app sẽ kiểm tra bản cập nhật mới ở kênh GitHub riêng. Chỉ hiện
  thông báo khi có phiên bản mới, tải ngầm và kiểm tra gói trước khi cho phép cài.
- Việc cài cập nhật cần xác nhận của người dùng, chỉ thực hiện khi phiên làm
  việc đã đóng; không tự ngắt Photoshop hoặc job đang chạy.

## Giữ nguyên

Luồng PNG/PSD, quy tắc tên, Smart Object, xử lý tuần tự, năm bảng màu và các công
cụ ảnh không thay đổi. Cài lại/cập nhật giữ cấu hình và dữ liệu hiện có.

## Cài đặt

Tải `PNG-Mockup-Setup.exe` và chạy trên Windows 10/11 64-bit. Bộ cài kèm Python,
Tk, Pillow và oxipng riêng; không cần app cũ hoặc Python cài sẵn. Máy dùng vẫn
cần Adobe Photoshop có Automation/COM hoạt động.

Bản 1.0.0 và bản 1.1.0 nội bộ chưa bật kênh GitHub cần chạy bộ cài phát hành
này một lần. Sau đó các bản mới hơn được phát hiện khi mở PNG Mockup đã cài.

Bộ cài chưa ký số. Không tắt các biện pháp bảo vệ Windows; đối chiếu file
SHA-256 đi kèm nếu cần. File `png-mockup-update.json` dành cho cơ chế cập nhật
của ứng dụng, không phải công cụ chạy riêng.
